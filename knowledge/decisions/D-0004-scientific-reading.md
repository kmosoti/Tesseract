# Source attributed scientific reading memory

## Observed

Workshop SI accepts a fixed experimental vocabulary. General scientific questions
need text and provenance beyond those four-state transition contracts. The
scientific corpus contains 15 revision-addressed English Wikipedia articles,
1,141 selected passages and 1,332 source MathML expressions. The dataset has a
separate CC BY-SA 4.0 notice.

Independent review found a presentation-to-algebra conversion error on absolute
value powers and integral limits. The importer now preserves source MathML and
uses explicit equation references instead of inferring algebra. Raw revision HTML
can be archived and checked against source hashes and complete extraction.

## Inferred

Declarative reading and validated numerical competence require different evidence.
Imported prose can support attributed retrieval without being promoted as a
workshop transition model or a verified scientific fact. A separate immutable
reading snapshot and explicit SI recall context preserve that distinction.

## Hypothesis

Source-attributed passage retrieval is a useful baseline for scientific reading.
It can expose missing prerequisites for later semantic reasoning without masking
them behind external language-model answers or fixed question-answer templates.
A lexical index is simpler to inspect and reproduce than adding a generative
model at this stage. It will fail on some paraphrases and unsupported premises.

## Unknown

Retrieval does not demonstrate entailment, scientific understanding, causal
reasoning, or theorem proving. The appropriate future representation for derived
scientific propositions remains open. Wikipedia selection and lexical relevance
do not establish scientific accuracy or completeness.
