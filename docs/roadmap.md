# Delivery and research work packages

These are implementation milestones, not declarations that hypotheses are true.
Each closes with a linked observation and a supported, inconclusive, or negative
verdict. Issue-ready records are in [issue-seeds.json](../.github/issue-seeds.json).

1. **Foundation and publication:** workspace, linked knowledge, deterministic
   world, bounded public contracts, CI, repository branches and verified remote
   controls. Administrative publication is tracked independently from local code.
2. **Kernel v0.1:** Bayesian, real, and complex candidate kernels; transition and
   sequence acquisition; automatic validation; provenance; persistence; rollback;
   matched transfer controls; bounded macro ablation; frozen benchmark verdict.
3. **Broader classical comparisons:** persistent graph/rules and VSA kernels
   implementing the same messages and experience splits; parameter/compute sweeps;
   preregistered capacity-matched follow-up with fresh evaluation seeds.
4. **Bounded ontology revision:** identify systematic residuals on development
   evidence; enumerate splits using up to two observed predicates; require held-out
   improvement with a complexity penalty and retained competence. Reject a split
   whose only benefit is a larger parameter budget compared with matched growth.
5. **Representation migration:** expand from dimension four toward eight using
   explicit isometries; version states, readouts, and channels together. Complete
   the channel on the new subspace, preserve old-space predictions before fitting,
   replay the migration, and support rollback. Expansion itself is not a learned
   distinction. Do not ship schema-changing migrations without these checks.
6. **Longer developmental sequences:** corrections, selective retraction,
   bounded-memory consolidation, new process compositions, and repeated shifts
   across sessions. Measure retention after later successful commits, not just
   storage of uncommitted evidence.
7. **Interfaces:** only after the learning instrument is qualified, consider
   language adapters and an inspectable UI. Keep language and neural adapters
   outside the cognitive kernel. Homeostatic regulation remains deferred.

Every follow-up proposal specifies public I/O, controls, budgets, falsification,
compatibility, and an untouched evaluation split before implementation begins.
